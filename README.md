# InteractiveVeil – Ephemeral Form Explorer

Projekt eksploruje koncepcję stopniowego odsłaniania ukrytych warstw obrazu i tekstu poprzez interakcję użytkownika.

## Kluczowe mechanizmy
- Ruch kursora → subtelne zmiany przezroczystości i skali warstw
- Kliknięcia → progresywne ujawnianie kolejnych poziomów treści
- Końcowy stan → powrót do jednolitego, monochromatycznego pola (symbol czystej koherencji)

## Inspiracje koncepcyjne
- Filozofia dekonstrukcji tożsamości
- Sztuka performance i body art
- Interfejsy dotykowe i relacje człowiek–maszyna

## Technologie
HTML5, CSS3, Vanilla JavaScript

## Uruchomienie
Otwórz index.html w przeglądarce lub użyj Live Server w VS Code.
